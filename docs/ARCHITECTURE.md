# 架构说明（ARCHITECTURE）

## 定位

「上岸计划」是一个 **AI 求职自动化智能体系统**：以对话式 AI 为执行大脑，
以确定性脚本流水线为骨架，以飞书多维表格为岗位库，以本地工作台/卡片为交互入口。
它同时具备 Agent（感知-决策-行动-记忆闭环）、Workflow（确定性流水线）、Web（界面层）三种属性。

## 核心数据流（每日）

```
抓取(感知) → 解析(详情) → 过滤(规则v5.2) → 通勤实测(高德)
  → 时效验证 → 增量去重 → 写多维表格 → 发每日卡片 → 用户投递
  → 反馈回写(已投/婉拒/已读不回) → feedback_learn 沉淀 → 次日规则更准
```

## 设计原则

1. **宁缺毋滥**：0 条达标就 0 条，绝不硬凑；已关闭岗位绝不推送
2. **可审计**：数字来自真实抓取验证；平台不可用如实标注受限原因
3. **外包硬排除**：外包黑名单（`rules.json`）优先级最高，绝不推送
4. **登录态看门狗**：`auth_guard` 拦截即停对应平台渠道，公开渠道不受影响
5. **反馈闭环**：婉拒/无效投递会进入规则学习，避免重复推同类岗位
