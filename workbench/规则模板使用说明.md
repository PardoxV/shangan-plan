# 上岸计划 · 求职筛选规则模板使用说明

> 一句话：**这是一份"帮我筛掉不合适岗位"的规则清单，存成一个 JSON 文件。你不需要会编程，改几个数字就能用它。**

---

## 一、这个模板是什么

「上岸计划」是一个把求职筛岗标准化的规则引擎。它把"什么岗位值得投"拆成了几组硬规则：

| 规则组 | 管什么 | 举例 |
|---|---|---|
| 通勤 | 岗位离你家多远算能接受 | 骑行 30 分钟内，或公交地铁 60 分钟内 |
| 薪资 | 到手多少钱才算能活 | 到手至少 5000 元/月 |
| 作息 | 休假要求 | 每周至少休 1 天，不接受轮班 |
| 排除角色 | 哪些岗位一律不碰 | 客服、主播、销售、电话外呼…… |
| 技能门槛 | 需要特定技能的岗位 | 要会剪辑/编程/英语六级的直接跳过 |
| 黑名单 | 哪些公司不投 | 外包公司、已知坑公司 |

规则模板文件（`rules-template.json`）就是把上面这些规则**打包成一个文件**。你拿到它，改改参数，就能拥有一套自己的筛岗标准。

---

## 二、怎么用（三步）

### 第 1 步：拿到模板

- 如果你在别人那里拿到 `.json` 文件，直接用它；
- 或者在你的本地工作台里点「规则中心 → 导出模板」，自己导出一份。

### 第 2 步：改参数（用记事本就能改）

用记事本（或 VS Code）打开 `rules-template.json`，找到想改的数字，直接改：

```json
"commute": {
    "bike_max_min": 30,        ← 骑行上限（分钟），你骑车能接受多远
    "transit_max_min": 60      ← 公交/地铁上限（分钟）
},
"salary": {
    "min_take_home": 5000,     ← 到手薪资底线（元/月）
    "max_push": 15000          ← 最高推到多少（太高的可能是坑）
},
"work_schedule": {
    "weekend_rest_min_days": 1 ← 每周至少要休几天
}
```

想改几个改几个，不动的就不用管。**注意：只改数字，别删引号、逗号、括号。**

### 第 3 步：导入

在本地工作台里点「规则中心 → 导入模板」，选这个文件，规则立刻生效。
岗位列表会实时显示：哪些岗位现在"达标"，哪些因为你的新规则被标红（⚠）。

## 三、每个字段是什么意思

### 1. `commute` 通勤
- `bike_max_min`：骑行最多多少分钟。例：`30` = 骑车半小时内到。
- `transit_max_min`：公交/地铁（含步行）最多多少分钟。例：`60` = 一小时以内。
- **规则**：骑行和公交**任一达标**就算合格（比如骑车要 45 分钟，但公交 35 分钟到，也算合格）。
- **提醒**：通勤时间必须按岗位详情页的**具体门址**实测（高德地图），不要按"这个片区大概不远"猜。

### 2. `salary` 薪资
- `min_take_home`：**到手**最低多少元/月（不是税前）。例：`5000` = 到手低于 5000 的岗位直接不投。
- `max_push`：超过这个数的岗位也不推。例：`15000` = 月薪标 2 万的反而警惕（可能是销售/外包画饼）。

### 3. `work_schedule` 作息
- `weekend_rest_min_days`：每周至少休息几天。
- `no_rotation`：是否不接受轮班制（`true`=不接受）。
- `legal_holidays_off`：是否要求法定节假日正常休（`true`=要求）。

### 4. `exclude_roles` 排除角色
这些词出现在岗位名里就直接跳过：客服、主播、销售、服务员、外卖、电话外呼、课程顾问……（默认 38 个词，可自己加减）。

### 5. `skill_gate` 技能门槛
- `user_lacks`：你自己**不会**的技能列表（默认：剪辑、UI 设计、写代码、英语四六级）。岗位要求这些技能 → 不投。
- `block_keywords_count`：硬性不推关键词数量（只是统计信息，不用改）。
- `override_pass_keywords`：豁免词。岗位描述里出现"接受无经验 / 可培训 / 零基础"这些词时，技能要求可以放宽。

### 6. `blacklists` 黑名单
- `outsource_companies`：外包公司名单（默认 46 家）。外包岗位通常稳定性差、成长有限。
- `company_blacklist`：公司黑名单（默认 64 家），踩过坑或口碑差的。
- 这两项默认**不拦截**，只作背景参考——你可以在工作台规则中心把"外包黑名单拦截 / 公司黑名单拦截"开关打开，才会真正排除。

### 7. `directions` 求职方向
你优先找什么方向（例：企业培训/教研课程 = 高优先级，行政/国企编外 = 低）。用于给岗位排优先级。

## 四、常见问题

**Q：改坏了文件怎么办？**
A：重新导出一份默认模板，或者在工作台点「规则中心 → 恢复默认」。

**Q：导入后没反应？**
A：检查文件是不是合法 JSON（可以用 [json.cn](https://www.json.cn) 这类在线工具粘贴验证）。确认后重新导入。

**Q：这个模板会改我的原始规则吗？**
A：不会。模板只写入工作台的"可调规则层"（override），权威规则文件 `rules.json` 永远是原始参考，不会被覆盖。

**Q：怎么把我的模板发给别人？**
A：直接把这个 `.json` 文件发过去就行。对方导入后改参数即可适配自己的城市/通勤/薪资。

**Q：黑名单为什么默认不拦截？**
A：作者本人的口径：外包/黑名单先当作"背景参考"看，不硬性一刀切——因为有些外包岗也有正经双休、薪资达标的。你可以按自己的情况把开关打开。
